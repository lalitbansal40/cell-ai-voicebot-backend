# Sample sheets (fake data)

Generated by `npm run samples:contacts` (`scripts/make-contact-samples.ts`) — deterministic, safe to commit. Used by the backend tests, the Playwright E2E suite and for trying imports by hand.

| File                       | What                                                                                            |
| -------------------------- | ----------------------------------------------------------------------------------------------- |
| `contacts-sample-100.csv`  | 100 borrowers (UTF-8 BOM, CRLF — like an Excel "CSV UTF-8" export) with a known mix of problems |
| `contacts-sample-100.xlsx` | The same rows as an Excel workbook (sheet "Borrowers")                                          |
| `dnd-sample.csv`           | 5 do-not-call rows (`Mobile`, `Reason`), 1 invalid                                              |

Columns: `Name, Mobile No, Email, Loan ID, Loan Amount, Due Date, DPD, Branch, Tags`. Amounts come in mixed formats (`5250`, `₹5,250`, `Rs. 5500`, `26750.50`); dates are `DD/MM/YYYY`.

## Expected result of validating `contacts-sample-100.csv`

Preconditions in the account (the tests set these up): a **required** currency field `loan_amount`; contacts that already exist for `+919000100086` and `+919000100087`; DND entries for `+919000100088` and `+919000100089`. Accept the suggested mapping (Loan ID → external id, Loan Amount → `loan_amount`, new fields `due_date` (date), `dpd` (number), `branch` (text)).

| Total      | Count | Rows                                                                                                                   |
| ---------- | ----- | ---------------------------------------------------------------------------------------------------------------------- |
| rows       | 100   |                                                                                                                        |
| created    | 87    | 85 new numbers + the 2 DND numbers (imported and flagged)                                                              |
| updated    | 2     | the 2 existing contacts (written with a leading `0`)                                                                   |
| invalid    | 8     | 5 bad phones (`12345`, `9.00011E+09` → "lost digits", `call later`, empty, `+91 12345`) + 3 rows without `Loan Amount` |
| duplicates | 3     | rows 99–101 repeat the phones of rows 2–4 in another format                                                            |
| dnd        | 2     | flagged, still imported                                                                                                |

Without a required `loan_amount` field the 3 "missing amount" rows are valid (created 90, invalid 5).

`dnd-sample.csv` against the same account: created 2, unchanged 2 (already listed), invalid 1.
