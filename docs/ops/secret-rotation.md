# Secret rotation runbook

**First rotation:** date to be set by the owner, after Meta App Review ends. Secrets were shared in chat during setup, so **every secret below must be rotated at least once**. Do the review account last, because Meta's reviewer uses it.

Rules: new values go only into the server env and the team password manager, never into chat, e-mail, git or screenshots. Rotate one secret at a time and verify before the next. Back up the old `ENCRYPTION_KEY` until `keys:reseal` reports 0 remaining.

| Secret                          | Who    | Steps                                                                                                                                                        | Effect                                                                        | Verify                                                                     |
| ------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Mongo URI password              | Client | New DB user / password in Atlas, update env, restart, remove the old user                                                                                    | Short restart                                                                 | `/api/v1/health`, login works                                              |
| `REDIS_URL` password            | Client | Update Redis and env, restart                                                                                                                                | Short restart; queued jobs stay                                               | Jobs run                                                                   |
| `JWT_ACCESS_SECRET`             | Client | Replace, restart                                                                                                                                             | Access tokens end; browsers refresh silently                                  | Stay signed in or sign in again                                            |
| `JWT_REFRESH_SECRET`            | Client | Replace, restart                                                                                                                                             | **Everyone signs in again**                                                   | Login works                                                                |
| `ENCRYPTION_KEY`                | Client | Move the old key to `ENCRYPTION_KEYS_OLD`, set a new key, restart, `keys:reseal --dry-run`, `keys:reseal`, remove the old key after 0 remaining and a backup | None for users. Signed file links in flight end                               | `keys:reseal --dry-run` reports 0; a WhatsApp send and a webhook test work |
| `SUPPRESSION_HMAC_KEY`          | —      | **Never rotate.** Changing it loses every suppression record                                                                                                 | —                                                                             | —                                                                          |
| OpenAI key                      | Owner  | New key, env, restart, revoke the old                                                                                                                        | None                                                                          | A test AI call                                                             |
| Meta App Secret                 | Owner  | Reset in Meta, update env, restart                                                                                                                           | Webhooks with the old signature fail during the switch: do it at a quiet time | Webhook test from Meta                                                     |
| Meta System User token          | Owner  | Generate, update where used, revoke the old                                                                                                                  | Reconnect any number connected with it                                        | `SYNC NOW` on the number                                                   |
| Razorpay keys + webhook secret  | Owner  | New keys, env, restart                                                                                                                                       | Payments in flight may need a retry                                           | Test top-up                                                                |
| SMTP password                   | Client | New password, env, restart                                                                                                                                   | None                                                                          | `tools.sh email:test`                                                      |
| Superadmin password             | Owner  | Change in the app                                                                                                                                            | Sessions end                                                                  | Login                                                                      |
| Review account (`metareview@…`) | Owner  | **After App Review ends:** change or disable it                                                                                                              | Meta can no longer log in                                                     | —                                                                          |

After rotating, note the date here (not the values) and check the code repo and old env files on laptops: delete local copies such as `~/Downloads/*.env*`.
