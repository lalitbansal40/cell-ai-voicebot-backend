# Data map

Every collection and file store, and what happens to its personal data. `src/modules/privacy/erase-map.ts` (contact erasure) and the account export and purge work from this table. `tests/security/data-map.test.ts` fails when a Mongoose model has no row here.

**Erase contact:** `delete` = rows removed · `scrub` = row kept, listed personal fields cleared · `keep` = kept on purpose (reason given) · `none` = no contact data.
**Export:** `yes` = in the account export · `no` = not included (reason in Notes).

## File stores

| Store                                  | Key source                                                          | Erase                                |
| -------------------------------------- | ------------------------------------------------------------------- | ------------------------------------ |
| Recordings                             | `calls.recording`                                                   | Delete with the call scrub           |
| WhatsApp media                         | `messages.media`, `inboxUploads.storageKey`                         | Delete with the message              |
| Imports and error reports              | `importJobs.fileKey`, `errorReportKey`                              | Delete when the file has the number  |
| Exports                                | `exportJobs.fileKey`, `accountExports.fileKey`                      | Delete when the file has the contact |
| Invoices                               | `invoices.pdfFileKey`                                               | Keep                                 |
| Flow audio, TTS cache, knowledge files | `flowAudio.fileKey`, `ttsCache.fileKey`, `knowledgeSources.fileKey` | Not contact data                     |

## Outside our systems

Chats on the customer's phone, data held by Meta, data sent earlier to a webhook receiver and Google Sheets are not ours to delete. The privacy policy says so.
