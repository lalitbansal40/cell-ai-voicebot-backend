# Rate limits

Generated by `npm run gen:rate-limits`. `tests/security/rate-limits.test.ts` fails when this file is out of date, or when a route with no sign-in has neither a limiter nor a reason here.

Every request also passes the global limit of 1,200 a minute per IP. API keys have per-key limits: 600 reads and 60 writes a minute by default.

## Routes with no sign-in

- `POST /api/v1/auth/signup`: own limiter
- `GET /api/v1/auth/signup-options`: own limiter
- `POST /api/v1/auth/verify-email`: own limiter
- `POST /api/v1/auth/login`: own limiter
- `POST /api/v1/auth/refresh`: own limiter
- `POST /api/v1/auth/logout`: no limiter. Origin checked; only ends the caller’s own session
- `POST /api/v1/auth/verify-email/resend`: own limiter
- `POST /api/v1/auth/forgot-password`: own limiter
- `POST /api/v1/auth/reset-password`: own limiter
- `POST /api/v1/webhooks/voice-api/a/{account}/{key}`: own limiter
- `POST /api/v1/webhooks/voice-api/{secret}`: own limiter
- `GET /api/v1/api-keys/whoami`: no limiter. Needs an API key, so the per-key limit applies
- `GET /health`: no limiter. Health check; cheap, no data
- `GET /ready`: no limiter. Blocked at nginx; internal only
- `POST /api/v1/webhooks/razorpay`: no limiter. Signed with HMAC over raw bytes; size limited
- `POST /api/v1/report-unsubscribe`: own limiter
- `GET /api/v1/system/info`: no limiter. Static build info
- `GET /api/v1/auth/invite-info`: own limiter
- `POST /api/v1/auth/accept-invite`: own limiter
