## 5. Deviations from the plan

All recorded in the [plan changelog](PHASE_8_PLAN.md#changelog) (batch 1, 2 and 3 entries). Batch 3 in short: the routes and `LIVE_PHASE = 8` moved from T8.10 to T8.11 (with the pages); the detail's Activity tab reads the campaign `history` (no per-target audit filter); `AUTH_RATE_LIMIT_MAX` (`450f9fa`; the suite signs up one account per spec and went over the default 30 per 15 minutes — the E2E backend sets 500); `GET /campaigns/summary` (dashboard card) and `adminPausedCampaigns` on the admin account detail were added so the card and the superadmin resume have data; result rows carry `waitReason`; "Call now" on the simulated line always answers (a manual call is made to hear the flow; customers still vary) and stays enabled for do-not-call / opted-out contacts so the guard's refusal explains why; an opt-out also puts the number on the do-not-call list, so the E2E preview counts 3 do-not-call skips (2 DND + 1 opted out) instead of "Opted out: 1"; the ₹20 wallet in the money spec is a superadmin credit (the smallest top-up is ₹100); the done-when spec turns customer callbacks off (a callback waits for its real time, tomorrow, so the run could not finish); bundle **+5.5 KB** over the 5 KB target (§4); the results table polls every 10 s while a campaign is active because live updates can be off (the realtime client stays off after a failed ticket fetch until the browser goes online again — Phase 3 behaviour, kept; see §7).

Real bugs found and fixed (each with a regression test): **Batch 1–2** — priority ignored (`24c6786`), shutdown not draining ticks / results (`7ac910d`), a cancel with hang-up missing calls being set up (`0ceeff2`), dry-run dials paced in real time (`4123da3`), no redial after a not-counted end (`6475603`), a flow that can no longer run kept failing calls (`ba1ce35`), a waiting campaign missed a changed window (`c50a7f9`), a progress update could crash the process (`5cd7abd`), the OpenAPI document lacked the campaign and top-up schemas (`9222044`) · **Batch 3** — result rows linked to the contacts tab instead of the contact page (fe `90df27e`), the tester's prefilled flow vanished while its picker searched (fe `5084890`) · **found by Playwright:** the dry-run minimum gap between calls was real time, so a ×20 run's retries waited 30 real minutes (`db3f9d0`) · Call now calls never updated the contact's call facts (`085c333`) and the contact page refreshed before the call ended (fe `2b87e5b`) · a Call now on the simulated line could be busy or unanswered (`f3948ca`) · page header subtitles nested chips (`<div>`) in a `<p>` (fe `985ffc7`) · the results table stayed stale with live updates off (fe `8e6d32e`). · **found by the second full E2E run:** a playground message typed while "Start new conversation" was on its way went to the previous conversation (Phase 5 code; fe `6ba53ab`).
