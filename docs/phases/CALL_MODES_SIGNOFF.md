## Deviations

1. **Pull instead of push (D8):** the agent's browser asks for the next call; there is no dispatcher reservation (Lua) and no `campaign.call_assigned` push. Reason: a human call's browser media attaches in the API process, while the dialer runs in the worker. One request = one call for one agent, so the same guarantees hold (never more live calls than free agents, nobody dialled without a person).
2. **Heartbeat (D7):** over HTTP every 10 s (30 s silent = away), not over the realtime socket. Redis key `cm:team:<campaignId>`.
3. **Tests:** Team → AI and line-busy cases live in `tests/calls-wa/inbound.test.ts`; team dialing is covered by `tests/campaigns/team-session.test.ts` with a stub call manager (no separate `team-dialing.test.ts` on fake ARI / Meta).
4. `dispositionSource` for agent outcomes is `user` (the existing value), not a new `agent`.
